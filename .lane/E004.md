## Independent intermediate contract

For input target `(tx,ty)`, offset `(ox,oy)`, and
`lambda=(ty-oy)/(tx-ox) mod p`, snapshot the public x/y registers after the
existing profile phase boundaries and compare against:

```text
after tlm_coord_add3x:
  x = tx - ox + 3*ox
  y = lambda
after square_product_register:
  x = tx - ox + 3*ox - lambda^2 = ox - rx
  y = lambda
after pp_mul_restore:
  x = ox - rx
  y = lambda * (ox - rx)
after tlm_coord_y_sub_final:
  x = ox - rx
  y = lambda * (ox - rx) - oy = ry
after tlm_coord_rsub_final:
  x = ox - (ox - rx) = rx
  y = ry
```

All arithmetic is modulo secp256k1 p. The tool must verify the base artifact
SHA and op count before applying the frozen tail nonce in memory, reproduce the
same Fiat-Shamir derivation and batch/lane as the unchanged evaluator, and run
all preceding batches so measurement RNG state is not silently changed.
